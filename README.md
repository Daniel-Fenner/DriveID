# DriveID
Projeto PMI | DriveID

Estacionamento inteligente, simples e automatizado.

O DriveID é uma solução de mobilidade urbana desenvolvida para tornar a experiência de estacionar mais rápida, prática e automatizada.

Inspirado em soluções de pagamento automático como o Sem Parar, o DriveID utiliza a placa do veículo como forma de identificação, permitindo automatizar o processo de entrada, permanência e pagamento em estacionamentos compatíveis.

Além da automação do pagamento, o aplicativo também permite que o motorista encontre estacionamentos próximos, visualize informações sobre eles e escolha a melhor opção para sua necessidade.
