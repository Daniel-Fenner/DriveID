# DriveID
Projeto PMI | DriveID

Estacionamento inteligente, simples e automatizado.

O DriveID é uma solução de mobilidade urbana desenvolvida para tornar a experiência de estacionar mais rápida, prática e automatizada.

Inspirado em soluções de pagamento automático como o Sem Parar, o DriveID utiliza a placa do veículo como forma de identificação, permitindo automatizar o processo de entrada, permanência e pagamento em estacionamentos compatíveis.

Além da automação do pagamento, o aplicativo também permite que o motorista encontre estacionamentos próximos, visualize informações sobre eles e escolha a melhor opção para sua necessidade.


Explicação dos arquivos e pastas do projeto:
Temos a pasta driveid-backend onde foi usado o node.js com Express para criar o backend do projeto, nessa pasta temos o .env para guardar as configurações do banco de dados, o arquivo index.js onde tem a rota e a pasta src onde esta organizado diferentes aspectos importantes do parte de backend do projeto como o routes que define os endpoints/rotas de veículos, o config que cuida da conexão com o banco de dados, o repositories que usa a conexão configurada em db.js para inserir o veículo no banco e devolve o resultado para o controller e o controllers que responde para o front-end com o status e os dados salvos.
Já na pasta driveid-frontend temos o script.js, o style.css e os varios arquivos html correspondentes as varias paginas do projeto.
O projeto foi escrito em conjunto entre os 3 membros e pode apresentar estilo de código e organização diferente completamente diferente ao longo dos arquivos.
